这篇既是**功能演示**，也是这个站的使用说明。看完你就知道每一层内容怎么放、怎么写。

## 一、写作在哪写

所有笔记都写在私有 Obsidian 库里（`Desktop/shawn2016`），**公开站点是同步出来的，不要直接改站点目录**。

```bash
# 写完 → 同步 → 预览 → 发布
python3 sync.py
cd site && ./build-local.sh
```

## 二、四层可见性

| 层级 | 怎么写 | 效果 |
|---|---|---|
| L0 公开 | `publish: true` | 搜索、图谱、RSS 全部可见 |
| L1 不索引 | `publish: true` + `unlisted: true` | 不进搜索/图谱/RSS，但知道链接能打开 |
| L2 加密 | `publish: true` + `password: __NOTE_PASSWORD__` | 需要密码才能看正文 |
| L3 私有 | 不加 `publish`，或放 `_private/` | 完全不生成、不进公开仓库 |

> [!warning] 边界
> 加密只防路人和搜索引擎，不防拿到源码的攻击者。公司密钥、客户数据一律 L3，永远不上站。

## 三、标签比目录重要

目录只做物理归档，**标签才是检索入口**。一条笔记通常打三类标签：

- 领域：`#ui` `#frontend` `#automation` `#rpa` `#ai` `#mcp`
- 类型：`#笔记` `#复盘` `#收藏` `#工具` `#踩坑`
- 成熟度：`#🌱发芽` → `#🌿生长` → `#🌳成熟`

点任意标签可以看聚合页，比如 #automation 。
