# 设计规范文档模板

## 一、定位

`design-spec.md` 是**约束文档**，不是设计稿说明书。每条规范必须能反过来判定「任意新页面是否合规」，因此采用「规则 / 可判定条件 / 反例 / 适用范围」四要素写法。

`design-tokens.json` 是规范的可机读子集，只放可量化变量；两者必须同源，不允许出现文档里写了而 token 里没有的色值或档位。

## 二、文档结构

```markdown
# 【项目名】设计规范

## 0. 文档信息
| 版本 | 日期 | 变更内容 | 依据 | 确认状态 |
|---|---|---|---|---|
| v0.1 | ... | 基础层（首页选定风格抽取） | 04-style-decision / 05-ux-review | 已确认 |

## 1. 适用范围与不适用范围
- 适用于：（页面清单、平台、本期范围）
- 不适用于：（标注原因，如运营活动页、第三方嵌入页）
- 上游依据：PRD vX.X / prototype vX.X / 设计基线 vX.X

## 2. 设计原则（3-5 条，每条可判定）
## 3. 基础层（v0.1 冻结）
### 3.1 色彩与语义色
### 3.2 中性色阶
### 3.3 字阶与字重
### 3.4 间距与栅格
### 3.5 圆角与描边
### 3.6 阴影与层级
### 3.7 图标语气
### 3.8 可访问性下限
## 4. 组件与状态层（S5 扩展）
### 4.1 导航与 tab
### 4.2 列表与卡片
### 4.3 表单与输入
### 4.4 按钮与操作
### 4.5 反馈与弹层
### 4.6 状态提示（空 / 载 / 错 / 成功 / 禁用）
## 5. 条款库（编号 SP-xx，四要素表）
## 6. 反例库
## 7. 例外与豁免（须写明批准人与失效条件）
## 8. 版本演进与变更记录
## 9. 合规声明
```

## 三、条款四要素表

```markdown
| 编号 | 规则 | 可判定条件 | 反例 | 适用范围 |
|---|---|---|---|---|
| SP-01 | 主色仅用于主操作与关键数值 | 单屏主色填充面积占比 ≤ X%；除主按钮与关键数值外不得出现主色块 | 用主色做大面积卡片背景 | 全部业务页 |
| SP-02 | 次级文字使用固定色阶 | 次级文字色值必须等于 token `neutral.secondary` | 临时用透明度自造灰字 | 全部业务页 |
```

判定条件必须可执行：数值比较、枚举白名单、集合包含、文件字段比对。**禁止**「协调」「舒适」「有质感」「适度」这类不可判定词。无法给出判定条件的观察，登记为「待观察项」，不写成规范。

## 四、基础层必备下限

| 项 | 必须写清 |
|---|---|
| 色彩 | 主色、成功/警告/危险、禁用态的色值与各自允许的使用场景 |
| 中性色阶 | 背景、面板、分隔线、主文/次文/占位文字，共几阶及各阶用途 |
| 字阶 | 字号阶梯列表、对应行高、标题/正文/辅助字重 |
| 间距 | 基础步长、页面边距、组内与组间间距档位（枚举，不得随意取值） |
| 圆角 | 卡片/按钮/输入/弹层四档值 |
| 层级 | 浮起、描边、纯色分隔各自适用场景 |
| 图标 | 线性/面性、线宽、尺寸档、是否随语义着色 |
| 可访问性 | 正文与背景对比度下限、最小可点击区域、不依赖单一颜色传达状态 |

所有数值标注来源：`参考取样观察 / 设计推导（标「推导」）/ 用户指定`。引用平台规范时给链接与查阅时间。

## 五、组件与状态层（S5 扩展规则）

组件层不得另起一套色值或档位，只能引用基础层 token 组合。新增条款前先确认：

1. 该组件或状态是否在页面清单中真实出现（登记缺口为准，不凭想象补）。
2. 是否已有条款可覆盖；能覆盖则只补充适用范围，不新增条款。
3. 新增条款是否影响已生成页面；影响时必须同步列出需回归的页面清单。

## 六、规范与设计稿的绑定

```markdown
| 页面 ID | 设计稿文件 | 适用条款编号 | 回归结论 | 规范版本 |
|---|---|---|---|---|
```

`07-spec-regression.md` 使用同一张表逐条判定。页面稿不是规范的「示例图」，而是规范的**受约束实例**：规范变更时，受影响页面必须重新回归。

## 七、示例条款（虚构示例，仅演示写法）

> 以下数值为示例，不代表任何项目真实取值，禁止直接套用。

- SP-01 主色 `#3A6FF7`（推导）仅用于主按钮与关键数值；单屏主色填充面积 ≤ 10%（推导阈值，需用户确认）。反例：主色铺满卡片背景。
- SP-04 间距只使用 4 / 8 / 12 / 16 / 24（推导，单位 px）五档；出现其他值即判定不合规。反例：卡片内边距 15px。

## 八、自检

- [ ] 每条 SP 条款四要素齐全且可判定
- [ ] 文档与 `design-tokens.json` 同源，无孤立色值/档位
- [ ] 所有数值有来源标注，推导值已标「推导」
- [ ] 例外与豁免有批准人与失效条件
- [ ] 版本演进记录了每次变更的影响范围
- [ ] 无绝对化用语与不可判定形容词
- [ ] 文末有合规声明
